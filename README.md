# HADA_Website_Template
AI-agent-operable framework for creating, rebuilding, migrating, maintaining, testing, and deploying websites. Designed for reusable site operations with CMS, RSS, PWA, static cache, automation, and external content integration. AI Agent対応のWebサイト運用フレームワーク。サイトの新規作成・復旧・移行・保守・テスト・公開を支援し、CMS、RSS、PWA、静的キャッシュ、自動化、外部コンテンツ連携に対応。
